# Rock-vs-Mine-Classification-using-Sonar-Dataset
The Sonar dataset contains signals bounced off rocks and mines (metal cylinders).
Task: Binary classification → Rock (R) or Mine (M).Source: UCI Machine Learning Repository (Sonar dataset). 
Features: 60 numeric attributes (sonar signal energy at different frequencies).  Target: Rock (R) or Mine (M). 
Size: 208 samples.
